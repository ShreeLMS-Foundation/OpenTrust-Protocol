# AISUS Rulebook

This folder contains separate normative rules for AISUS so organizations can adopt, audit, and version each rule independently.

## Rule Index

- `RULE-01-LEGAL-COMPLIANCE.md`
- `RULE-02-PRIVACY-PROTECTION.md`
- `RULE-03-HARM-PREVENTION.md`
- `RULE-04-RESPONSIBLE-USE.md`
- `RULE-05-TRANSPARENCY.md`

## Adoption Guidance

- Treat all rules as mandatory baseline controls.
- Add stricter local controls if required by law or sector regulations.
- Keep change logs when modifying rule text for downstream distributions.
