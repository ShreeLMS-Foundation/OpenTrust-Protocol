# Contributing to AISUS

## What to Contribute
- Policy refinements
- New rule proposals
- Safer filter patterns
- Risk scoring improvements
- Integration examples

## Contribution Checklist
- Explain problem and impact.
- Include test/demo evidence.
- Update docs if behavior changed.
- Keep security and privacy implications explicit.

## Rule Change Process
1. Open proposal issue.
2. Reference impacted rule file(s).
3. Submit PR with rationale and compatibility notes.
4. Require one maintainer review before merge.
