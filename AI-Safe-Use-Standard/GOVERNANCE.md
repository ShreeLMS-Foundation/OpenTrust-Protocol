# AISUS Governance

## Roles
- **Maintainers:** merge and release responsibility.
- **Safety Reviewers:** review sensitive rule/implementation changes.
- **Contributors:** submit improvements and examples.

## Decision Process
- Minor text/code fixes: maintainer approval.
- Rule semantics changes: maintainer + safety reviewer approval.
- Breaking changes: public proposal issue and migration note.

## Release Cadence
- Patch: as needed for urgent safety updates.
- Minor: monthly rule and implementation improvements.
- Major: when rule model or risk model changes materially.
